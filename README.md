## Instalasi & Menjalankan 🚀

1.  Clone repositori: `git clone https://github.com/muhammadyusri121/uaspember`
2.  Masuk ke direktori: `cd uaspember`
3.  Install dependensi: `flutter pub get`
4.  Jalankan proyek: `flutter run` (Pastikan Anda memiliki emulator Android atau perangkat yang terhubung)
